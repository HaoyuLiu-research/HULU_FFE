# Measured Data of a 7-tap Analog Feed-Forward Equalizer
This repository contains measured data of a 7-tap analog feed-forward equalizer (FFE). The shared data include measured bathtub curves, channel frequency responses, eye diagrams, group delay, and SNDR.

## Measurement Setup
A 1.0-Vpp 212.6-Gb/s PRBS11 PAM-4 signal generated by an arbitrary waveform generator (AWG) passes through test channels consisting of phase shifters, coaxial cables, and PCB traces. The 7-tap analog FFE compensates for the channel loss, and the output is captured by an oscilloscope for time-domain analysis. The frequency responses are measured using a vector network analyzer (VNA). 

## Dataset Description

### 1. Bathtub curves 
Bathtub curves extracted from measured PAM-4 waveforms.
Files: 
	bathtub curves/bathtub_25.4dB.csv: bathtub curve data of the 25.4-dB channel
	bathtub curves/bathtub_30.9dB.csv: bathtub curve data of the 30.9-dB channel

### 2. Channel frequency responses
The frequency responses of the test channels measured using a VNA.
Files: 
	channel frequency responses/CH1_25.4db@53GHz.s4p: 4-port s-parameter of the 25.4dB channel
	channel frequency responses/CH2_30.9db@53GHz.s4p: 4-port s-parameter of the 30.9dB channel

### 3. Eye diagrams
Measured 212.6-Gb/s eye diagrams.
Files: 
	eye diagrams/25.4-db Link.png: eye diagram of the 25.4-dB link.
	eye diagrams/30.9-db Link.png: eye diagram of the 30.9-dB link.
	eye diagrams/AWG output.png: eye diagram from a direct AWG-to-scope connection.

### 4. Group delay
The group delay of the analog FFE is calculated from the measured S-parameter using a 4-GHz aperture. 
Files: 
	group delay/group delay.csv

### 5. SNDR
Measured SNDR of the 25.4-dB link with and without the analog FFE under different levels of additional noise intentionally added to the AWG output.
Files:
	SNDR/SNDR comparison.xlsx: The SNDR values as a function of the added noise amplitude.
	SNDR/FFE coefficients.xlsx: Coefficients of the TX FFE, analog FFE, and scope FFE used in the measurement.
